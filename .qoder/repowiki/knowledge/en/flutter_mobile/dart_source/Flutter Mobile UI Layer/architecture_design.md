The module is organized under `lib/ui/` with a clear two-tier split:
- `core/` holds cross-cutting UI concerns: `theme.dart` defines `AppColors` (a Tailwind-mirrored dark palette) and `AppTheme` (light/dark/system `ThemeData` resolution), while `widgets/code_block.dart` provides a reusable syntax-highlighted code block with copy and HTML preview toggle.
- `features/` groups feature screens as independent Flutter widgets, each in its own subdirectory (auth, camera, chat, home, settings, sidebar, voice). Feature screens are mostly stateless presentational widgets that accept data and callbacks via constructor parameters; stateful screens (AuthScreen, SettingsScreen, VoiceScreen) manage local form controllers, animations, and service calls but delegate business logic upward through callbacks.
- Dependency direction is one-way: features import `ui/core/theme.dart` for design tokens and never the reverse. Cross-feature communication happens only through callback props passed from parent screens, keeping features decoupled.
