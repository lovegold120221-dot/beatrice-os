The module is a standard Flutter Android application (`com.eburon.beatrice`) built with Kotlin and Gradle Kotlin DSL. `MainActivity` extends `FlutterActivity` and acts as the single entry point that registers three independent `MethodChannel` bridges — `MobileUseChannel`, `OcrChannel`, and `LivePcmAudioChannel` — each owning its own channel name and method dispatch table. Long-running or privileged work is delegated to two Android components declared in `AndroidManifest.xml`: `MobileUseRuntimeService` (a foreground service managing task lifecycle, notifications, and SharedPreferences persistence) and `MobileUseAccessibilityService` (an AccessibilityService providing screen reading, text input, tap/swipe gestures, and app launching). Cross-component communication uses a static `@Volatile` reference pattern: `MobileUseChannel.activeChannel` holds the current MethodChannel for callbacks from the runtime service, and `MobileUseAccessibilityService.instance` exposes the singleton accessibility service instance. The build targets Java/Kotlin 17, minSdk 26, and links the Tesseract4Android library for local OCR; signing is configured via `key.properties` and ProGuard rules are enabled for release builds.
