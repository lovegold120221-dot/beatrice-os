The `src/app` layer is the Next.js App Router shell (`layout.tsx`, `page.tsx`) that renders the BeatriceVoice chat interface. All AI provider logic lives under `src/services/` as independent modules (gemini.ts, ollama.ts, flux.ts, etc.) that expose a common function-calling contract via `tools.ts` (tool declarations + `executeTool`). Cross-cutting state and persistence are centralized in `src/lib/supabase.ts`, which both the UI and services consume for auth, memory, and profile storage. The UI imports services directly rather than going through an API route, making this a client-side-first architecture where the browser calls AI providers and persists data to Supabase.
