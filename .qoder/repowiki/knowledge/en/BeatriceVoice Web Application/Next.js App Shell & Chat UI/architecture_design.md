Built on Next.js App Router with a minimal root layout (`layout.tsx`) that sets page metadata and imports `globals.css`, which configures Tailwind v4 theme tokens (Inter + JetBrains Mono fonts) and markdown styling. The entire UI lives in `page.tsx`, a large client component (`"use client"`) that owns all application state (messages, view routing between home/chat/models, auth, device profile, provider selection). Backend integration is split across three layers: a Next.js Route Handler at `api/ollama/models/route.ts` proxies to a local Ollama instance via `OLLAMA_BASE_URL`; business logic for Gemini, Ollama, Flux image generation, tools, memories, and profiles is imported from sibling `../services/*` modules; persistent storage uses Supabase (`supabase.auth`, `chats`/`messages` tables, storage bucket `chat-images`). Real-time voice interaction is implemented inline with Web Audio API `AudioWorkletNode`s for PCM encoding/decoding and streams audio to Gemini's live session API. Settings are persisted both in `localStorage` (keys prefixed `eburon_`) and via `saveDeviceProfile` to Supabase.
