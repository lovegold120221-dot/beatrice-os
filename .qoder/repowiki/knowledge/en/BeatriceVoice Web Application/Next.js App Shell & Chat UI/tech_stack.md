Next.js App Router with React Server Components for layout and client components for the app shell; Tailwind CSS v4 via `@import "tailwindcss"`; Lucide React icons; `motion/react` for animations; `react-markdown` for rendering model responses; Supabase for auth, Postgres (chats/messages tables), and storage; Gemini SDK for streaming chat and live voice; Ollama as an optional local LLM backend via a Next.js route proxy.
